A few practical questions

Can we collect data offline?

The mobile workflow supports prepared forms and offline collection. Synchronisation needs connectivity; live API lookups and web forms require an internet connection.

Can a form support multiple languages?

XLSForm supports labels in multiple languages. Use the official form-design guide to structure your language columns.

How do we discuss deployment and licensing?

Contact RTA with your project requirements, or start with the self-hosted deployment guide. Pricing and licensing should be confirmed for your setup.
